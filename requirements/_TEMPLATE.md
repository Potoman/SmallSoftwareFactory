# REQ-000 — Short requirement title

## Description

What the software must do, from the user's point of view.
Be factual and precise: inputs, outputs, rules, edge cases.

## How to test

Verifiable steps, each with its expected result. Example:

1. Run `<command>` with `<input>`.
   → Expected: `<exact output or measurable criterion>`.
2. Error case: `<invalid input>`.
   → Expected: `<message / exit code>`.
